# COMP3123 Lab 2

Phillip Onofua · 101489064

Array methods, promises and fetching JSON with JavaScript.

## Files and run commands

From this folder, run `node Lab2_array_methods.js` for the array examples.

Open `Lab2_promise.html` through a local web server and inspect the browser console for the Promise and fetch examples. `Lab2_promise.js` demonstrates promise handling; `Lab2_fetch.js` requests a third-party Netflix status endpoint. That example requires internet access and a response from the external service. No npm packages are required.
