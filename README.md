## Running the labs

- **Lab 1:** `node labs/lab1/Lab1_node.js` (port 8088). Open its HTML file for the JavaScript review.
- **Lab 2:** `node labs/lab2/Lab2_array_methods.js`; open the HTML example through a local web server for browser exercises.
- **Lab 3:** `cd labs/lab3`, then `npm ci` and `node main.js` (port 8088).
- **Labs 4–6:** follow the README in each folder for installation, routes and testing. Lab 6 requires your own private MongoDB configuration.
- **Week 9:** `cd labs/lab9`, then `npm ci` and `npm run dev`. Use `npm run build` to build the app.
- **Lab Test 1:** follow its README for the individual question commands.
